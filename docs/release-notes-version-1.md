# Project Mayhem — Version 1

Project Mayhem is an offline-first Android Markdown editor for creating stylized, borderless A4 PDFs directly on your device.

## Highlights

- Live A4 document preview
- Markdown editor with formatting shortcuts
- Configurable title typography, metadata, layout, and footer
- Optional colour image, caption, placement, and watermark
- Standard and negative output modes
- Optional password-protected PDFs
- One-time output-folder setup
- Direct PDF saving to the folder you choose
- No account, Internet permission, or broad storage permission

## Requirements

- Android 8.0 or newer
- Enough storage for the APK and generated PDFs

## Installation

1. Download `Project-Mayhem.apk` from the assets below.
2. Verify it using `Project-Mayhem.apk.sha256` if possible.
3. Open the APK and allow installation from the browser or file manager when Android asks.
4. Launch Project Mayhem.
5. Select an output folder and confirm **Use this folder**.

## Privacy

Project Mayhem renders PDFs locally. It does not request Internet access or unrestricted storage access. PDFs are written through Android's Storage Access Framework to a folder selected by the user.
